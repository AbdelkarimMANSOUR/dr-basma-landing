# Images

Place the following image files in this folder before deploying:

| File | Description |
|------|-------------|
| `hero.jpg` | Reception photo with logo (used as hero background) |
| `waiting.jpg` | Waiting area photo |
| `care.jpg` | Exam / care room photo |
| `lounge.jpg` | Lounge chairs + shelves photo |
| `logo.png` | Clinic logo (transparent background preferred) |

## Recommended dimensions

| File | Recommended size |
|------|-----------------|
| `hero.jpg` | 1600 × 900 px minimum (16:9) |
| `waiting.jpg` | 800 × 600 px (4:3) |
| `care.jpg` | 800 × 600 px (4:3) |
| `lounge.jpg` | 800 × 600 px (4:3) |
| `logo.png` | 300 × 300 px (square, transparent bg) |

Optimise all images for web (WebP or compressed JPEG) before uploading.
